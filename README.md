# 🌦️ اپلیکیشن هواشناسی صفی‌آباد

یک اپ وب هواشناسی (PWA) با طراحی مشابه اسکرین‌شات‌های ارسالی، کاملاً فارسی و راست‌چین.

**این پروژه هیچ وابستگی به Android Studio ندارد.** فقط HTML، CSS و JavaScript خالص است و مستقیماً در مرورگر (دسکتاپ یا موبایل) اجرا می‌شود و از طریق مرورگر قابل «نصب» روی گوشی است (PWA).

## ✅ ویژگی‌ها (مطابق صفحات اسکرین‌شات)

| صفحه | توضیح |
|---|---|
| ساعتی | ساعت آنالوگ زنده + دما، رطوبت و احتمال بارش هر ساعت |
| روزانه | پیش‌بینی ۷ روز آینده + خلاصه وضعیت هفته |
| نقشه و رادار | نقشه با لایه رادار بارش زنده (RainViewer) روی نقشه OpenStreetMap |
| اطلاعات | فشار هوا، UV، جهت باد، طلوع/غروب، کیفیت هوا (AQI)، نقطه شبنم |
| هشدارها | هشدارهای خودکار بارش شدید / باد شدید / UV بالا بر اساس پیش‌بینی |
| تنظیمات | تغییر مکان پیش‌فرض (جستجوی شهر یا موقعیت فعلی)، واحدها، تم روشن/تیره |

## 📍 موقعیت پیش‌فرض

موقعیت پیش‌فرض برنامه **صفی‌آباد، بخش کوهسارات، شهرستان مینودشت، استان گلستان** است (بر اساس لینک نقشه گوگل ارسالی). این مختصات تقریبی است؛ کاربر می‌تواند از صفحه «تنظیمات» آن را به هر شهر یا روستای دیگری تغییر دهد یا از دکمه «استفاده از موقعیت فعلی من» استفاده کند.

مقدار پیش‌فرض در فایل `js/app.js` قابل ویرایش است:

```js
const DEFAULT_LOCATION = {
  name: "صفی‌آباد",
  region: "مینودشت، گلستان",
  lat: 37.32,
  lon: 55.15
};
```

اگر مختصات دقیق‌تری برای این نقطه دارید، فقط کافیست مقادیر `lat` و `lon` را در همین فایل جایگزین کنید.

## 🌐 منبع داده آب‌وهوا

داده‌های آب‌وهوا به‌صورت **زنده و رایگان** (بدون نیاز به کلید API) از سرویس [Open-Meteo](https://open-meteo.com) دریافت می‌شود:

- پیش‌بینی ساعتی/روزانه: `api.open-meteo.com/v1/forecast`
- جستجوی شهر: `geocoding-api.open-meteo.com/v1/search`
- کیفیت هوا: `air-quality-api.open-meteo.com/v1/air-quality`
- رادار بارش زنده: `api.rainviewer.com`
- تبدیل مختصات به نام شهر (دکمه موقعیت فعلی): `api.bigdatacloud.net`

> لینک گوگل که برای «هواشناسی صفی‌آباد» ارسال شده بود صرفاً یک صفحه نتایج جستجوی گوگل بود و API عمومی و پایداری ندارد؛ به همین دلیل از Open-Meteo به‌عنوان منبع داده واقعی و قابل‌اتکا استفاده شده است.

## 🚀 اجرای محلی

نیازی به نصب چیزی نیست. کافی است فایل `index.html` را در یک سرور محلی ساده باز کنید (به دلیل service worker، بهتر است از طریق یک سرور محلی اجرا شود نه مستقیماً از فایل):

```bash
# با پایتون
python3 -m http.server 8080
# سپس در مرورگر باز کنید:
# http://localhost:8080
```

یا با هر ابزار مشابه مثل `npx serve` یا افزونه Live Server در VS Code.

### نصب روی گوشی (بدون Android Studio)
1. سایت را در مرورگر (کروم/سافاری) باز کنید.
2. از منوی مرورگر گزینه «افزودن به صفحه اصلی / Add to Home Screen» یا «نصب اپ» را بزنید.
3. اپ مانند یک اپلیکیشن مستقل روی گوشی نصب می‌شود.

## 🤖 استقرار خودکار با GitHub Actions

فایل `.github/workflows/deploy.yml` شامل یک workflow است که با هر push به شاخه `main`:

1. فایل‌های JS و JSON را از نظر صحت سینتکس بررسی می‌کند.
2. یک فایل `weather-app.zip` از کل پروژه می‌سازد و به‌عنوان Artifact قابل دانلود در تب Actions قرار می‌دهد.
3. کل پروژه را روی **GitHub Pages** منتشر می‌کند (رایگان، بدون نیاز به سرور).

### راه‌اندازی GitHub Pages
1. مخزن (repository) را در گیت‌هاب بسازید و این فایل‌ها را push کنید.
2. در تنظیمات مخزن به مسیر `Settings → Pages` بروید و در قسمت **Source** گزینه **GitHub Actions** را انتخاب کنید.
3. با هر push به `main`، سایت به‌صورت خودکار در آدرسی شبیه `https://USERNAME.github.io/REPO-NAME/` منتشر می‌شود.

## 📁 ساختار پروژه

```
weather-app/
├── index.html              صفحه اصلی و ساختار همه‌ی صفحات
├── manifest.json            تنظیمات PWA (نصب روی گوشی)
├── service-worker.js        کش آفلاین فایل‌های برنامه
├── css/style.css            استایل کامل برنامه
├── js/app.js                منطق برنامه، دریافت داده، نقشه، هشدارها
├── js/weathercodes.js        نگاشت کدهای هواشناسی + تقویم شمسی
├── icons/                    آیکون‌های PWA
└── .github/workflows/deploy.yml   بیلد و استقرار خودکار
```

## ⚠️ نکات

- هشدارهای صفحه «هشدارها» بر پایه آستانه‌های احتمال بارش، سرعت باد و شاخص UV از داده‌های پیش‌بینی Open-Meteo محاسبه می‌شوند و جایگزین هشدارهای رسمی سازمان هواشناسی نیستند.
- تقویم شمسی به‌صورت محلی و بدون کتابخانه خارجی محاسبه می‌شود.
- برای تغییر واحد دما (سلسیوس/فارنهایت) و سرعت باد از صفحه تنظیمات استفاده کنید.
