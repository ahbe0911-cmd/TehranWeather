# هواشناسی صفی‌آباد — Flutter Native

این پوشه نسل جدید برنامه است و مستقل از نسخه PWA قبلی ساخته می‌شود.

ویژگی‌های فعلی:
- Flutter Native Android
- GPS واقعی با درخواست مجوز Android و دقت بالا
- نمایش مختصات و دقت GPS
- Reverse Geocoding برای نام منطقه/شهر
- داده زنده بدون API Key از Open-Meteo
- پیش‌بینی ۲۴ ساعت و ۷ روز
- کش آخرین وضعیت برای حالت آفلاین
- رابط RTL فارسی و تاریخ شمسی
- پس‌زمینه زنده، ابر، باران، برف، شب و انیمیشن‌های حرکتی

پروژه Android در CI با Flutter ایجاد می‌شود و سپس سورس Native از `source/lib` روی آن اعمال می‌شود.
